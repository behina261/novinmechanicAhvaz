# نوین مکانیک اهواز | Novin Mechanic Ahvaz

قالب اختصاصی وردپرس شرکت **نوین مکانیک اهواز**؛ یک وب‌سایت چندصفحه‌ای و چندزبانه برای معرفی شرکت، خدمات صنعتی، پروژه‌ها و مسیرهای ارتباط و دریافت درخواست مشتریان.

> نسخه قالب: **6.0.0**  
> زبان‌ها: فارسی، انگلیسی و چینی  
> نوع پروژه: قالب اختصاصی WordPress

## معرفی پروژه

این مخزن کد قالب اختصاصی وب‌سایت نوین مکانیک اهواز را نگهداری می‌کند. ساختار قالب برای معرفی خدمات و توانمندی‌های صنعتی شرکت طراحی شده و بخش‌هایی مانند معرفی شرکت، خدمات، پروژه‌ها، گالری تصاویر، محصولات، اطلاعات تماس و فرم‌های دریافت درخواست را در بر می‌گیرد.

## امکانات و بخش‌ها

- رابط چندزبانه فارسی، انگلیسی و چینی
- صفحات معرفی شرکت، خدمات، پروژه‌ها، گالری و تماس
- دسته‌بندی و نمایش پروژه‌ها در چهار حوزه:
  - تعمیرات اساسی
  - تأمین
  - مهندسی
  - ساخت
- اجزای مستقل صفحه در پوشه `template-parts/`
- داده‌های پروژه‌ها، محصولات و گالری در پوشه `data/`
- فرم استعلام و فرم ارسال رزومه
- تنظیمات اختصاصی قالب از پیشخوان وردپرس
- خروجی‌های مرتبط با SEO، نقشه سایت و مسیرهای چندزبانه
- فایل‌های CSS، JavaScript، فونت‌ها، تصاویر و ویدئوی پس‌زمینه در پوشه `assets/`

## پیش‌نیازها

- WordPress نسخه **6.0 یا بالاتر**
- PHP نسخه **8.0 یا بالاتر**
- وب‌سرور سازگار با وردپرس
- برای ارسال مطمئن ایمیل فرم‌ها، پیکربندی SMTP روی هاست توصیه می‌شود.

## نصب قالب

1. مخزن را دریافت یا Clone کنید.
2. پوشه قالب با نام `novin-mechanic` را در مسیر زیر قرار دهید:

   `wp-content/themes/novin-mechanic/`

3. وارد پیشخوان وردپرس شوید.
4. از مسیر **نمایش ← پوسته‌ها**، قالب **Novin Mechanic** را فعال کنید.
5. تنظیمات قالب را بررسی و اطلاعات واقعی شرکت را تکمیل کنید.

## پیکربندی پس از نصب

پیش از انتشار وب‌سایت، فایل [FILL-ME.md](FILL-ME.md) را مطالعه و موارد ناقص را تکمیل کنید. از جمله:

- متن‌های معرفی شرکت، چشم‌انداز، خدمات، تعهدها و سایر متن‌های زبان‌ها در `lang/`
- اعداد واقعی آمار شرکت
- نشانی Embed نقشه
- تصاویر و نام محصولات
- لینک فایل کاتالوگ PDF
- ساعت کاری
- کلیدهای اختیاری Cloudflare Turnstile برای مقابله با هرزنامه

اطلاعات و محتوای واقعی شرکت باید توسط مالک پروژه تأیید شوند؛ مقادیر نمونه یا خالی را به‌عنوان اطلاعات قطعی منتشر نکنید.

## بررسی و آزمون

پس از نصب، از [TEST-CHECKLIST.md](TEST-CHECKLIST.md) برای بررسی صفحات، نسخه‌های زبانی، منوی موبایل، لینک‌دهی بخش پروژه‌ها، فیلتر و نمایش تصاویر، فرم‌ها، نقشه سایت و خروجی‌های SEO استفاده کنید.

پیشنهاد می‌شود آزمون‌ها ابتدا روی محیط آزمایشی (Staging) انجام شوند و سپس نسخه تأییدشده روی وب‌سایت اصلی قرار گیرد.
